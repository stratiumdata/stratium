# Security Policy

Stratium is an authorization system, so a bypass is a security bug even when it
looks like a logic bug. If a hostile enforcement point (PEP) can get a better
answer by lying, that is in scope.

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new), not in a
public issue. Include the request or tool call, the decision you got, and the
decision you expected.
