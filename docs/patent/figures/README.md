## Notes

- These are draft engineering diagrams, not formal patent drawings.
- Each figure is aligned to `docs/patent/03-figure-descriptions.md`.
- The `.svg` files are black-and-white drafts intended to be easier for counsel or a patent illustrator to refine for filing.
- A patent illustrator or counsel can later simplify line weights, labels, and callouts for final submission.
